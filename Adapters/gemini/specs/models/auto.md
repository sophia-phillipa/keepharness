# Gemini CLI `auto-gemini-3`

`auto-gemini-3` is Gemini CLI's automatic Gemini 3 model alias exposed by Tail Harness. It is account-dependent and does not assert plan entitlement, a concrete provider model version, or an API model identifier.

The harness passes the configured model argument unchanged and exposes only `configured` effort. Reassess this record when the installed CLI is verified or the model catalogue is integrated.
