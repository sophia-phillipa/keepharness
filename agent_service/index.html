Conexão / MCP

O modelo e esforço padrão do MCP são definidos no painel administrativo deste servidor, em Configurações → Conexão / MCP. Se o cliente informar modelo ou esforço, sua escolha tem prioridade.

Use o servidor pelo Claude

No notebook Linux ou Mac, mantenha o Tailscale conectado e tenha Python 3.10+, curl e Claude Code instalados. Baixar instalador MCP (.sh). Salve em Downloads. No Mac, abra o Terminal pelo Spotlight (⌘ + Espaço, digite Terminal). Execute os comandos abaixo: chmod +x torna o arquivo executável. Se salvou em outra pasta, ajuste o primeiro comando.

No Claude Code, use /mcp para conferir a conexão. Depois peça: “Use o tail-harness para consultar os modelos, selecionar meu projeto e delegar esta tarefa”.
Para Claude Desktop, abra as instruções completas. O conector roda no notebook e conversa pela Tailscale, sem endpoint público.
