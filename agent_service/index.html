    The MCP's default model and effort are set in this server's admin panel, under Settings → Connection / MCP. If the client specifies a model or effort, its choice takes priority.

    Use the server from Claude

    On your Linux or Mac laptop, keep Tailscale connected and have Python 3.10+, curl, and Claude Code installed. Download the MCP installer (.sh). Save it to Downloads. On Mac, open Terminal via Spotlight (⌘ + Space, type Terminal). Run the commands below: chmod +x makes the file executable. If you saved it to a different folder, adjust the first command.

    In Claude Code, use /mcp to check the connection. Then ask: “Use tail-harness to check the models, select my project, and delegate this task”.
    For Claude Desktop, open the full instructions. The connector runs on your laptop and communicates over Tailscale, with no public endpoint.
