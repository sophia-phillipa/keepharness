# Top bar and conversation titles

Global bar above the panels, with collapse/expand conversations on the left and activity on the right. The right panel ends at the window edge, below the bar; the internal close button was removed. The quota indicator is hidden for the local model and returns for cloud providers.

The conversation header uses the title instead of the project selector: New Conversation outside a project, New Conversation in the project followed by its real name before the first message in a project. Afterward it uses a trimmed excerpt of the first message or the renamed title; long text gets an ellipsis. The project stays internally associated and selectable from the sidebar.

New Conversation sits below Conversations and starts a conversation outside a project when project-less mode is authorized. Each project has a similar, smaller button, also called New Conversation.

Validation: `tests/harness-topbar.spec.cjs` passed on desktop and mobile, including the initial connection block, panel positions, local/cloud quota and initial titles. JavaScript syntax validated and the AST map updated. No Git milestone.
