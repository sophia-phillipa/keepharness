# Version 0.4.3 — Actual local context capacity

The local model catalog queries the authenticated runtime `/props` endpoint and exposes `default_generation_settings.n_ctx` as `context_window`. Queries are concurrent with a two-second timeout. The harness uses this capacity for local-model context denominators and percentages, including reopened conversations; the Codex model metadata default is not a valid local-server capacity. Unavailable capacity is omitted rather than invented. Nonlocal providers keep their reported window. Token usage and throughput are unchanged.

No state migration. Reload the harness after a runtime context change. Validation: syntax and live catalog response only; no inference or benchmark.
