# D-029 — Every parity WP gets a visible pass before merge

Status: accepted. Date: 2026-10-05. Decided by: Sophia ("always visible", as relayed by the coordinating session). Spec: [How](../codex-parity-design.md#how).

## Context

Parity packages were validated by specs and reviews, but Sophia watches the real app to judge Codex fidelity.

## Decision

Each WP gets a visible pass in the real app on Sophia's screen right after its review fixes and before merge.

## Rationale

Codex fidelity, spacing and theme contrast are visual qualities that headless specs do not prove.

## Alternatives

Merge on green specs and review alone, with a visual tour later.

## Impact

Merge order of every parity WP; release-note validation sections record the visible pass.
