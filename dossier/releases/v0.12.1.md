# Version 0.12.1 — Integrated catalog and workspace gauntlet baseline

## Behavior

This release merges `main` 0.11.1 (`2819d26`) into the P5 0.12.0 branch
(`8d49da6`) with a non-fast-forward merge. It preserves catalog
manifests, private pins and update previews, credential bindings, drift reporting,
write ownership and independent provider lanes alongside the workspace sections,
Run console sizing and visual regression suite from 0.11.1.

Chat remains home. The mock-4 structure and the approved scale at 100% browser
zoom remain the reference. The right pane contains Files, Background tasks,
Resources and Activity. Manifest readiness and catalog pin metadata remain visible
when resources are inspected from the pane or the `/` palette. Local administration
retains Catalogs and vault, including explicit pin updates and write-only secrets.

The visual matrix retains 216 workspace screenshots and adds 72 P5 admin
screenshots: vault, pins/update preview and drift report across the same six themes
and four viewports (288 matrix screenshots per full run). Screenshots use synthetic
fixtures and temporary output directories. Geometry, accessibility and behavioral
assertions are executable contracts; captured images are evidence, not committed
pixel baselines or proof of validation with real users.

The product remains **Tail Harness**. `control/product.py` remains the source of
name, slug, MCP identity, environment prefix, state paths and branding. It has no
release-version field: the separate package/runtime identifiers, HTML labels,
Gemini `clientInfo`, current README references and tour revision are 0.12.1.
The generated identity consumers retain the P5 `PRODUCT` contract.

## Acceptance criteria

- Both merge parents remain in history, with all earlier release notes retained.
- P5 catalog, vault, pin, drift, write ownership and lane contracts continue to pass.
- The workspace sections and Run console preserve 0.11.1 behavior and mock-4 scale.
- Resources and `/` expose applicable manifest and pin data consistently.
- P5 admin states join the visual matrix without weakening existing assertions.
- The Python suite, including slow tests, passes; environment/live skips are named.
- The complete UI suite passes twice on fresh, available ports after checking the
  served version and instance. All persona specs are included.
- Convention checks and wheel/sdist builds pass. English and Portuguese READMEs
  have identical headings in identical order.

## Integration regressions and review

- The resource palette did not display the catalog pin commit. A failing browser
  assertion reproduced the missing `Pinned`/short-commit metadata. A shared formatter
  now supplies the palette, resource preview and workspace rows, including source
  versus pin status and dirty state. Resource revision remains distinct from catalog
  commit. Targeted slash/workspace assertions passed after the change.
- The first full UI diagnostic run reproduced a selector collision in
  `gauntlet-resource-send`: an unscoped resource selector clicked the new workspace
  row before the palette option arrived, leaving `@review` unchanged. The regression
  explicitly selects and checks the palette option role, retaining the exact draft
  whitespace, submission snapshot and resource-selection assertions. The focused
  regression passed; two clean complete runs follow this correction.
- Independent review corrected commit/revision terminology and restored creation
  of an explicitly supplied admin evidence directory. No assertion was relaxed.
- Read-only comparison captures against the supplied mock-4 preserved the center
  chat, approved scale, 300px sidebar, approximately 390px workspace and Run console
  expansion. These establish structural fidelity, not pixel equivalence.

## Migration

No schema migration, product rename, directory relocation or credential migration
is introduced. Existing P5 catalogs, pins, bindings and project state remain valid.
Existing 0.11.1 installations gain the optional P5 facilities described in
[0.12.0](v0.12.0.md), including its permissions and isolation limits. Refresh browser
assets after upgrading. The tour uses the 0.12.1 revision.

No live account, cloud inference, model download or client data is required by the
campaign. Publication and external integrations are outside this release validation.
