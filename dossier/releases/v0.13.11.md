# Version 0.13.11 — Round-eleven isolation, workflow and plan editing

## Behavior

- Redaction state is isolated by provider source and channel, bounded without evicting unfinished credentials. Service diagnostics and audit records are sanitized, and delayed responses revalidate current authority.
- Local session mounts exclude runtime-private targets. Catalog pins materialize validated immutable blobs without mutable checkout callbacks.
- Gates retain expiry/cancellation outcomes through SQLite writer contention. Worker shutdown remains interruptible; restart invalidates pending gates.
- MCP Resume/rerun expose caller idempotency keys. Workflow saves reject existing logical IDs/names; bounded scanning and unavailable YAML parsing return explicit errors. Selected resources are checked again after waiting for provider capacity. Nonportable source paths are unavailable during discovery.
- Interrupted root answers and portable history omit delegated child text, while attributed events remain available.
- The plan editor exposes task text, model, effort, reorder, remove and reset controls. Serialized drafts remain compatible with existing storage, and server-side approval validation remains authoritative.
- File trees support managed keyboard focus, directional traversal and expansion semantics. Folder redraws retain focus, and Escape closes a conversation menu without closing a workspace pane.
- Timeline metadata does not overlap. Publication evidence and complete default Pipeline cards share the viewport; tour highlights follow visible target bounds. Chat remains home, with no global scale reduction.

## Acceptance criteria

All 18 round-eleven findings have reproducible regressions. No raw credential reaches diagnostics/history, no stale selected definition dispatches after a capacity wait, and cancelled/expired gates do not remain orphaned in a live worker. Ordinary plan prose survives reload and reaches the approved persisted plan unchanged. Visual acceptance uses actual text rectangles and pointer hit tests at native zoom, including all three themes.

## Migration

No schema migration or configuration change is required. Existing plan drafts retain their JSON storage format. Callers may supply `idempotency_key` to both MCP recovery tools; absent keys retain existing behavior. Unsupported invocation source paths require renaming the source file or directory. YAML remains optional; saving refuses to assume uniqueness when an existing YAML document cannot be parsed. Local adapter specification revision is 3. Persisted `sem-projeto` and Tailscale identifiers are unchanged.
