# Release 0.13.5 — gauntlet round five

## Behavior

Chat remains home at the approved 100% scale. Fresh 1024px workspaces use mock-4's 260px/340px side panes; existing custom widths remain respected. Persisted protocol and Tailscale identifiers are unchanged.

- Pinned catalogs enumerate ignored and untracked additions regardless of Git status configuration. Local read-only mounts reject hardlinks to runtime-private files and resolve relocated private roots; ordinary read-only hardlinks remain supported. A losing native approval receives a terminal conflict.
- Workflow inputs reach both builtin and resource-backed step prompts. Generated and manually edited plans enforce declared permissions, integrations, operations and modes before execution. Only standalone structured result fences drive conditions; absent or malformed results require review even for a null output schema.
- Recovery projections check current workflow and dependency revisions. Missing bound inputs produce an actionable error before enqueue and the same classified failure if removed after admission. Native resource recovery uses the provider's actual default execution mode.
- An unavailable unpinned Git catalog produces a diagnostic without hiding unrelated project resources. Exact agent/skill IDs disambiguate shared names. External Codex catalog skills require an existing native skill registration; directory links remain supported, while file-only aliases are not advertised as executable.
- Successful submission retires deferred draft writes. Pending plan edits share the existing storage retry/warning mechanism, survive browser reload, and supply the exact plan approved from Chat, Needs you or Run console. Opening a live conversation immediately persists its selection.
- Mobile workspace dialogs isolate covered content in the accessibility tree and own the visible persistent toolbar. About and completed tours restore focus to a visible active surface. Named About, Settings and Attention controls have at least 24px targets; the Attention popover stays in the viewport.
- Publication evidence retains a usable scrolling region alongside the console. Latest-message navigation stays clear of the header, and truncated activity summaries disclose their full text.

## Acceptance criteria and migration

All 26 input findings require reproduction and disposition. The resource-recovery execution-mode defect found during validation is tracked separately as R5-V1. Tests use synthetic state, actual browser geometry/hit tests, and adapter argument capture without cloud inference.

No database migration is needed. A read-only project containing a hardlink to runtime-private configuration or backups must remove the alias or use a different folder. Hardlink preflight covers existing aliases, not concurrent modification by a trusted host process. Unregistered external Codex skills remain visible with a preflight explanation until the owner registers them in a native skill directory. No host skill directories are modified automatically.
