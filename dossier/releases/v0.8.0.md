# 0.8.0 — Portable invocations, slash palette and human option gates

## Behavior

Chat remains the home screen. One `/` palette groups Agents, Skills, Commands,
Built-in controls (`/model`, `/effort`, `/access`) and Maintenance. Fuzzy filtering,
arrow keys, Enter, Tab, Escape, source badges, removable chips and a chain preview
make explicit execution reviewable. Search uses Ctrl/⌘+K. Files, Activity and
Settings stay reachable; the palette and gate cards fit a 400 px viewport.
Sent bubbles retain resource chips. Answer attribution comes from execution events;
child stream text does not become the main answer.

`Invocation` carries a portable resource ID, kind, verbatim args, ordered position,
inline/conversational/delegated mode and optional backend. Composer references and
legacy planner steps normalize to this contract. `maestro.plan()` and
`execute_plan()` are separate; declared chains bypass planning, validate each
step's policy and stop at the first incomplete or failed result. Conversational
roles remain in the main thread and are rejected inside multi-step chains. Use
**End agent conversation** before selecting another resource; the next message
commits the explicit release.

Discovery uses project > catalog > user precedence. Admin-registered trusted
catalogs permit bounded symlink targets; other escapes remain excluded. Large
commands remain listed, fenced examples do not trigger shell-expansion blocking,
and metadata includes namespaces, argument hints, first-sentence descriptions,
preflight guidance and honest compatibility. Rules/context are visible but not
selectable. `catalog.py` uses the same discovery path.

Typed option gates validate choices and persist a single resolution with owner
and timestamp. Competing replies return `gate_already_resolved`. Only an enrolled
human session can resolve gates; local access, bearer tokens, MCP and `full` access
cannot become approval authority. Restart invalidates pending gates explicitly;
replayed cards offer guidance to ask again. Claude AskUserQuestion is the first
consumer, returning chosen labels through `updatedInput.answers`.

## Compatibility and fallbacks

- Claude enables `Task` only with an explicit project `delegate` grant. Observed
  `Agent` events and `parent_tool_use_id` retain child correlation. `TodoWrite` is
  not enabled.
- Installed Claude commands use native slash pass-through where the command can
  remain the complete leading request. Catalog-only commands and requests with
  history/source context expand inline; this loses native command-frontmatter
  routing and is reported as a fallback.
- Catalog Claude agents receive validated temporary definitions through `--agents`.
  Installed CLI help confirms that surface. Offline protocol tests verify the
  adapter; this added materialization path was not certified by a new paid probe.
- Codex prompts expand inline. Agent TOML uses temporary regular copies through per-process config overrides;
  this override route is offline validated, without a new paid probe. Skill
  directories retain their supported native references.
- Claude rules use regular temporary copies with paths metadata in advisory
  prompt context. This preserves instructions without claiming native path-rule
  semantics for external symlinks.
- Hooks default to `--setting-sources project`; `services.claude.global_hooks: true` in admin settings additionally
  requires the hooks grant. Events label disabled/project/global-and-project
  scope. An explicit hook list alone does not suppress global hooks.
- Claude account connectors remain `unknown`. Codex option-question capability
  remains dependent on Plan mode or the experimental provider flag; the existing
  Harness approval fallback remains available. No task is silently switched to Plan.

## Acceptance criteria

- Synthetic catalog installed by symlinks is discovered from an unrelated project,
  including a command larger than 64 KB and maintenance entries.
- Fenced `$VAR` does not cause a false unsupported result; untrusted path escapes
  remain unavailable with no external file execution.
- `/demo--reviewer` uses a real adapter protocol path with recorded synthetic
  delegation events; an unrelated global auto-update hook remains outside the
  default settings scope.
- AskUserQuestion displays typed options and only an enrolled human can resolve it.
- Keyboard selection, replay, focus restoration and mobile width are covered by
  deterministic browser regressions. Assertions are retained when rerunning flakes.

## Migration and configuration

No existing project, owner, Tailscale or `sem-projeto` identifier changes. Existing
legacy planner JSON remains accepted. The additive `gates` table retains audits;
pending entries are invalidated at service initialization. Resource selections
from older drafts can require reselection because portable resource IDs replace
path-derived identifiers. Trusted catalogs are explicit admin settings, never
inferred from arbitrary symlinks. Project `catalogs` selects registered catalog IDs.
The documented `TAIL_HARNESS_LIVE=1` opt-in now governs all imported P0.5 probes.
