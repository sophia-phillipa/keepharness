## brand-deepseek

- Source: Simple Icons, `icons/deepseek.svg` (https://github.com/simple-icons/simple-icons, https://cdn.jsdelivr.net/npm/simple-icons@16.34.0/icons/deepseek.svg).
- Version: `simple-icons` 16.34.0 (npm, `latest` on 2026-10-06).
- License: CC0 1.0 Universal (public domain dedication). Tabler Icons 3.49.0 ships no DeepSeek icon.
- Edits: only the `<path d>` data is used, unchanged. It is wrapped in a `<symbol viewBox="0 0 24 24" fill="currentColor" stroke="none">`, like the other brand symbols, so it follows the text color. The Simple Icons brand color is not used.
- Trademark: the mark itself belongs to DeepSeek. It is used only to identify the DeepSeek provider in the UI.
